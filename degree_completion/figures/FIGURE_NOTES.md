## Figure 1 — Initial model comparison

**Files:** `figure1_initial_model_comparison.png` / `.svg`
**On-chart title/subtitle:** "Word Count Beats the Engineered Pipeline" / "Held-out PR-AUC, same
709-comment test set for all three models"

### 1. Source notebook and exact cells
`this work/04.2_baseline_comparison.ipynb`: cell 9 (`baseline_results` — engineered pipeline,
majority-class, stratified-random), cell 10 (adds TF-IDF + LogReg), cell 33 (`length_vs_others` —
adds `word_count` alone).

### 2. Exact values used
| Model | PR-AUC |
|---|---|
| Engineered-feature pipeline (229 features, XGBoost + SMOTE) | 0.3848 |
| TF-IDF + Logistic Regression | 0.5119 |
| Word count alone (1 feature) | 0.5256 |
| No-skill baseline (majority class) | 0.2031 |

### 3. Dataset and evaluation population
Full dataset (3,971 comments, 401 threads). Thread-grouped `GroupShuffleSplit` (80/20,
`random_state=42`): train 3,262 / 320 threads, **test 709 comments / 81 threads** — zero thread
overlap, verified by assertion. All three models and the no-skill baseline are evaluated on the
identical 709-comment test fold.

### 4. Metric definitions
PR-AUC (average precision), chosen over accuracy/ROC-AUC because the positive class
(`is_convincing`) is a minority (~20% on this test fold). No-skill baseline =
`DummyClassifier(strategy='most_frequent')`'s PR-AUC, which equals the test-fold's own positive
rate by construction — the correct reference for PR-AUC, not 0.5 and not the whole-dataset rate.

### 5. Uncertainty / error bars
**None shown on the chart.** All three values are single-split point estimates — no bootstrap CI
or order-robust averaging was computed for this specific three-way comparison. A related check
elsewhere in `04.2` (cells 12–14) found the engineered pipeline's point estimate (0.3848) sits
about 1 SD above its own order-robust mean (0.3676±0.0182), but that check was not repeated for
all three models side by side, so no number is shown here rather than approximated.

### 6. Methodological limitations
- Single train/test split; most pairwise PR-AUC differences in this project have overlapping
  bootstrap confidence intervals at this sample size.
- The engineered pipeline was *not* originally built with `word_count` as a feature — that fix is
  a separate, later result (not shown on this chart; see `PRESENTATION_STORYLINE.md` Section 3).
- Do not read this as "engineered features are useless" — only that this specific 229-feature
  pipeline, as selected, underperforms two much simpler baselines on this test fold.

### 7. One-sentence takeaway
On this task, how much someone wrote predicted persuasion better than a carefully engineered
229-feature pipeline did.

### 8. Suggested speaker notes (~25–30 seconds)
"We started with an elaborate feature pipeline — 229 engineered features, selected through a
systematic model-comparison grid. Its held-out PR-AUC was 0.38. A much simpler TF-IDF baseline,
with no engineered features at all, scored 0.51 — better. Digging into why led to something
almost embarrassingly simple: a single feature, word count, scored even higher — 0.53. That
finding reframed the rest of this project: comment length is a dominant signal, and the real
question became whether anything *beyond* length also matters."

## Figure 2 — Incremental value of rhetorical strategies

**Files:** `figure2_strategy_incremental_value.png` / `.svg`
**On-chart title/subtitle:** "Strategy Scores Add +0.0735 PR-AUC" / "Scored subset, n=2,753 (test:
592 comments)"

### 1. Source notebook and exact cells
`this work/06_strategy_ablation.ipynb`, cell 17 (`headline_df`), built on the order-robust
evaluator in cells 10–15 and the column-order sensitivity check in cells 11–14.

### 2. Exact values used
| Model | PR-AUC mean | PR-AUC SD |
|---|---|---|
| Engineered features (no strategy scores) | 0.4467 | 0.0196 |
| Engineered features + 8 strategy scores | 0.5202 | 0.0177 |
| Strategy scores only | 0.3538 | 0.0079 |
| No-skill baseline (scored subset) | 0.2382 | — |

Gain shown on-chart (bracket annotation): **+0.0735** (0.5202 − 0.4467).

### 3. Dataset and evaluation population
LLM-scored subset (comments ≥30 words, or any length if convincing): 2,753 comments, 400 threads.
Thread-grouped split: train 2,161 / 320 threads, **test 592 comments / 80 threads**. Different
population from Figure 1 — its own no-skill baseline (0.2382) is not comparable to Figure 1's
(0.2031).

### 4. Metric definitions
Held-out PR-AUC, **mean ± SD across 8 random orderings** of the same fixed column set (same
architecture throughout: `XGB (over)` + `SMOTE`, selected in `04.1`/`04.2`).

### 5. Uncertainty / error bars
**Error bars are ± 1 SD across 8 random orderings of the same feature columns, fitting the
identical fixed architecture on the same train/test split each time — only column order changes.**
`06` cells 11–14 found this exact pipeline is sensitive to column order (reshuffling alone swings
PR-AUC by up to 0.0422 on an identical 237-column set), traced to XGBoost's deterministic
tie-breaking among near-equal split gains on correlated features. **These are explicitly NOT
bootstrap confidence intervals, and they are NOT evidence of statistical significance** — they
describe sensitivity to an arbitrary implementation detail (column order), not sampling
uncertainty or a formal significance test. State this plainly if asked.

### 6. Methodological limitations
- Both arms are evaluated on the LLM-scored subset, not the full dataset.
- The +0.0735 gain is larger than the column-order noise band (combined SD of the two means being
  compared), so it is not an ordering artifact — but it is a single dataset's result, not yet
  shown to replicate (replication is addressed by Figure 6/7, not this chart).
- Strategy scores are LLM-generated measurements on a 1–5 rubric, not direct observations of a
  mental state or ground-truth human annotations (see Figure 5's reliability caveat).
- "Strategy scores only" (0.3538) sits between no-skill and the full model — real standalone
  signal, but not a replacement for the engineered feature set.

### 7. One-sentence takeaway
Adding eight LLM-scored rhetorical-strategy measures produces a real, order-robust improvement in
predicting persuasive comments.

### 8. Suggested speaker notes (~30–35 seconds)
"Length isn't the whole story, so we asked whether *how* an argument is made adds anything on top
of how much was written. We scored every comment on eight rhetorical strategies — refutation,
justification, use of evidence, and others — on a 1-to-5 scale using an LLM. Adding those eight
scores to the existing engineered features lifted PR-AUC from 0.45 to 0.52. The error bars here
aren't the usual confidence interval — they come from a quirk in this specific model: with over
200 correlated columns, just the *order* you feed them to XGBoost shifts the score by up to 0.04.
So every number here is averaged over several column orderings, and this gain comfortably
survives that averaging."

## Figure 3 — Rhetorical-strategy gain under length matching

**Files:** `figure3_strategy_gain_length_matching.png` / `.svg`
**On-chart title/subtitle:** "Strategy Gain Survives Length Matching" / "Incremental PR-AUC gain,
full vs. length-matched population" (shortened 2026-10-15; the decile-bin matching detail moved
from the subtitle into the footer and the speaker notes below, per a request to keep subtitles
short and move technical explanation off the chart).

### 1. Source notebook and exact cells
`this work/06_strategy_ablation.ipynb`: cell 31 (why `04.3`'s sample isn't reused here), cell 32
(builds the strict 1:1 match within the 2,753-row scored population by binning `word_count` into
10 deciles and randomly sampling matching counts of non-convincing comments from each convincing
comment's bin — **a decile-bin match, not a search for the single nearest-length comment**), cells
34–35 (`length_benchmark_df`).

### 2. Exact values used
| Population | n | Strategy-score gain (PR-AUC) |
|---|---|---|
| Full scored population | 2,753 | 0.0664 |
| Length-matched (within scored population) | 1,235 | 0.0557 |

Retention: 0.0557 / 0.0664 = 83.9%, shown on-chart as **84% retained**.

### 3. Dataset and evaluation population
Full scored population: 2,753 comments, test-fold positive rate 0.2382. Length-matched sample:
1,235 comments (decile-bin matched within the scored population), test-fold positive rate 0.5132.
Both rows use a fresh thread-grouped 80/20 split specific to that row's sample. `word_count`
correlation with the outcome drops from r=0.2882 (unmatched) to r=0.0608 (matched) — matching
worked, though a small residual correlation remains (decile bins, not exact pairs).

### 4. Metric definitions
Strategy-score gain = PR-AUC(engineered features + 8 strategy scores) − PR-AUC(engineered features
alone), both arms order-robust means over 8 column orderings, on the same population/split.
Retention % = (gain on matched sample) / (gain on full population) × 100.

### 5. Uncertainty / error bars
**None shown, intentionally.** The notebook reports an order-robust SD for each of the four
underlying PR-AUC arms, but does **not** compute an uncertainty estimate for the *gain* itself (a
difference of two means) or the *retention percentage* (a ratio of two gains). Showing error bars
here would require inventing an uncertainty figure that doesn't exist in the notebook. **The 84%
figure is a descriptive point estimate, not the result of a formal statistical test, and it does
not prove the strategy-score gain is fully independent of length** — it shows the gain holds up
much better than other feature families' lifts do under the same kind of matching, nothing
stronger. (The chart carries a one-line version of this caveat directly under the "84% retained"
callout.)

### 6. Methodological limitations
- **This length-matched sample is a separate, differently-built construction from
  `04.3_length_controlled_analysis.ipynb`'s own strict 1:1 match.** `04.3`'s sample is built from
  the *full* 3,971-row dataset; `06`'s sample (shown here) is built from the *2,753-row LLM-scored
  subset* only. The two are not combined on this chart or in this retention statistic.
- Matching substantially reduces sample size (2,753 → 1,235) and statistical power.
- "The gain survives matching" supports additional predictive signal beyond length; it does not
  establish full independence from length, and it does not establish that rhetorical strategies
  *cause* persuasion (predictive association only).
- A related, separate correction: `06_strategy_ablation.ipynb` cell 36's own markdown previously
  mis-cited a "25%" retention figure for the engineered pipeline (confusing it with a different
  quantity from `04.3`); corrected 2026-10-14 — see `PRESENTATION_STORYLINE.md`'s verification
  checklist. That figure is not used anywhere in this chart or these notes.

### 7. One-sentence takeaway
Once comment length is controlled for, the predictive gain from rhetorical-strategy scores barely
shrinks — unlike most other signal in this project.

### 8. Suggested speaker notes (~30–40 seconds)
"Showing that strategies help isn't enough, since we already know length dominates everything
else — the real question is whether the strategy gain is *also* just a length proxy. We built a
length-matched sample: for every convincing comment, non-convincing comments drawn from the same
word-count decile bin, not hand-picked nearest-length pairs. What this chart shows is the specific
*gain* from adding the eight strategy scores on top of the engineered features, before and after
that matching — it drops only from 0.066 to 0.056, about 84% retained. I want to be precise about
what that number is: a descriptive point estimate on one matched sample, not a significance test.
(Elsewhere in the same notebook, each arm's own overall lift-over-no-skill does drop more sharply
under matching — not shown on this chart — which is the context for why this gain's own retention
is the more notable number.) This is the strongest evidence in this project that the strategy
scores capture something beyond comment length, short of a formal independence test."

## Figure 4 — Comment length by outcome

**Files:** `figure4_comment_length_by_outcome.png` / `.svg`
**On-chart title/subtitle:** "Convincing Comments Are Much Longer" / "Word-count distribution by
outcome, full dataset (n=3,971)"

### 1. Source notebook and exact cells
`this work/04.2_baseline_comparison.ipynb`, cell 30 (`word_count` computation, correlation, class
means) and cell 31 (`plot_feature(word_count_trimmed, ...)` — the original notebook chart and its
<600-word trim). The raw word-count array plotted here was recomputed, read-only, from
`results/03_cmv_comments_df.csv.zip` using the exact same one-line formula as cell 30
(`cleaned_final_comment.fillna('').apply(lambda s: len(s.split()))`) — no model was fit or rerun.

### 2. Exact values used
Mean word count (full dataset, n=3,971): **non-convincing 78.0, convincing 216.7** (cell 30).
Point-biserial correlation r=0.3716, p=2.92e-130. Class sizes: 3,330 non-convincing (83.9%), 641
convincing (16.1%).

### 3. Dataset and evaluation population
Full dataset, 3,971 comments. The displayed histogram is **trimmed to <600 words** (matching the
notebook's own cell-31 cutoff), which excludes 56 comments (1.4% of the dataset, almost all very
long non-convincing comments) — the chart's footer states this exclusion. The two vertical mean
lines use the **full, untrimmed dataset's** means (78.0 / 216.7), not the trimmed subset's
slightly different means, per the task's requested values.

### 4. Metric definitions
Comment word count, computed on `cleaned_final_comment` (the same cleaned text TF-IDF is built
from — URLs/punctuation already stripped). Histogram shown as **density** (not raw counts) per
class, bin width 50 words, so the two very differently-sized classes' *shapes* are comparable on
one y-axis; actual class sizes are stated in the legend so the imbalance isn't hidden by the
density normalization.

### 5. Uncertainty / error bars
Not applicable — this is a descriptive distribution chart, not a model estimate.

### 6. Methodological limitations
- The original notebook's own chart (`plot_feature`, `show_counts=False`) shows *convincing rate
  per bin*, not an overlaid distribution — this figure is a new, purpose-built chart (an overlaid
  density histogram) built to satisfy "show the distribution … without hiding class imbalance,"
  not a re-export of the notebook's own plot.
- Correlation is not causation: longer comments correlate with being convincing, which is the
  confound the rest of the project investigates, not a claim that length *causes* persuasion.
- A within-thread check elsewhere in the project (not shown on this chart) confirms this isn't a
  pure topic/thread-size artifact: the convincing comment in a thread is longer than that thread's
  own non-convincing average in 153/200 (76.5%) of threads checked (Wilcoxon p=4.15e-19).

### 7. One-sentence takeaway
Convincing comments are, on average, nearly three times longer than non-convincing ones — the
visual root of the length confound that motivates the rest of the talk.

### 8. Suggested speaker notes (~25–30 seconds)
"Here's the length confound directly. Non-convincing comments average 78 words; convincing ones
average 217 — almost three times longer. The two distributions overlap a lot, so length alone
doesn't perfectly separate the classes, but the shift is large and it's the single strongest
correlate of persuasion we find anywhere in this project. And it's worth saying plainly: only 16%
of comments in this dataset are convincing at all — that imbalance is itself part of why we use
PR-AUC rather than accuracy throughout."

**Visual note:** Concession's two values (0.3439 / 0.3445) are only 0.0006 apart — closer than the

### 3. Dataset and evaluation population
Same two populations as Figure 3: the 2,753-row scored population (full) and its own 1,235-row

the fixed `XGB (over)` + `SMOTE` architecture fit on the 9-column `strategy scores + word_count`
model (`06`'s winning combination), per `07`'s own setup (cell 19).

### 4. Metric definitions
Mean absolute SHAP value per feature — how much that feature moves the model's output, on average,
across test-set comments. `word_count` is **excluded from the chart** because its SHAP value
(1.02/0.84) dwarfs every strategy's (max 0.60) and would compress the strategy comparison onto an
unreadable sliver of the axis; its dominance is already established in Figures 1–4.

### 5. Uncertainty / error bars
Not applicable — SHAP values here are point estimates from one fitted model per population, not
averaged over repeated fits or column orderings in this notebook.

### 6. Methodological limitations
- **SHAP importance is not a causal-effect estimate.** It measures how much a feature moves one
  fitted model's predictions, not how much that rhetorical strategy *causes* persuasion.
- Strategy scores are LLM-generated measurements on a 1–5 rubric. **Refutation and justification —
  the two strategies this figure foregrounds — were also the two strategies
  `05_rhetorical_scoring.ipynb`'s own validation flagged as hardest for the LLM to calibrate
  against human judgment** (lowest exact-match agreement in both the test-retest and small
  hand-scoring checks, N=18 single judge). The strongest findings in this figure come from the
  two most noisily-scored strategies — state this directly alongside the finding, not as a
  distant footnote.
- SHAP importance and the model-free Mann-Whitney effect size (Figure 6) measure different things
  and can disagree — see Figure 6's notes for the precise disagreement on CMV's "top" strategy.

### 7. One-sentence takeaway
Refutation keeps its predictive importance once comment length is controlled for; justification's
drops sharply — one plausible reading is that its apparent importance was partly a length proxy,
though the data alone don't prove that interpretation.

### 8. Suggested speaker notes (~30–35 seconds)
"We can ask the model directly which strategies it's actually using, via SHAP. On the full
population, refutation is the most important strategy, well ahead of justification in second
place. Once we control for length — same matched sample as the last slide — refutation barely
moves, staying clearly in first place. Justification's importance drops sharply, falling behind
concession, simplification, and evidence. One reasonable interpretation is that much of what the
model was using justification for was tracking length rather than justification itself — but
that's an interpretation of the pattern, not something this comparison proves on its own. One
honest caveat on top of that: these are also the two strategies our LLM scorer
agreed with human judgment on the least — the strongest finding here is also the least reliably
measured one."

### 2. Exact values used

### 4. Metric definitions
Rank-biserial correlation from a Mann-Whitney U test (convincing vs. non-convincing comments'
score distributions for each strategy), FDR-corrected (Benjamini-Hochberg) across the 8
simultaneous tests, in **both** datasets, using the identical procedure — this is what makes the
cross-dataset comparison methodologically valid.

### 5. Uncertainty / error bars
Not applicable to the chart directly — significance (FDR < 0.05) is encoded via filled vs. hollow
markers rather than numeric error bars, since the underlying quantity (rank-biserial r) does not
have a symmetric SD/CI reported in either notebook in a form suitable for plotting here.

### 6. Methodological limitations
- **Precision matters here: justification has the highest rank-biserial effect size in the CMV
  (home) dataset — not refutation.** Refutation leads CMV by **SHAP importance** (Figure 5,
  0.6034), a different metric measuring a different thing (a fitted model's use of the feature vs.
  a model-free univariate separation). The two methods disagree on which strategy is "the" top
  strategy at home; this figure states that disagreement directly rather than picking one metric
  silently.
- The headline reversal this figure is built to show is narrower than "refutation vs.
  justification swap first place" — it's `evidence` that makes the single largest jump (6th at
  home → 2nd on WA), and `refutation` that drops the most among previously-strong strategies (2nd
  at home → 4th on WA), while `justification` stays 1st in both.
- `personal_narrative` is not significant at home but becomes significant (small, positive) on WA
  — the one strategy whose significance status itself flips.
- This is one specific effect-size method; it is not identical to, and can disagree with, the SHAP
  ranking (Figure 5) or any future model-based ranking on WA.

### 7. One-sentence takeaway
This is not a simple refutation↔justification swap: justification leads by this metric in both
datasets, while evidence rises sharply (6th→2nd) and refutation falls (2nd→4th) between them.

### 8. Suggested speaker notes (~35–40 seconds)
"We re-ran the same strategy-vs-outcome test on a completely different corpus — Winning Arguments,
from r/ChangeMyView's own subreddit rules dataset used elsewhere in the literature. Same method,
same statistical test, both datasets. Justification is the top strategy by this metric in both —
but look at refutation: second at home, it drops to fourth on WA. And evidence does the opposite,
jumping from sixth to second. So the broad claim — rhetorical strategies carry signal beyond
length — holds up on an independent dataset. But the specific story about *which* strategy matters
most doesn't transfer cleanly, and I want to flag precisely: even at home, refutation's claim to
being 'the' top strategy depended on which method you ask — SHAP says refutation, this effect-size
test says justification."

### 3. Dataset and evaluation population
WA corpus: 8,096 scored comments (8,106 collected, 10 dropped for unparseable LLM responses).
Native WA train/heldout split (not re-split by this project): **train 6,584 comments, heldout
1,512 comments** — the same partition the dataset ships with and the literature's own benchmark is
computed on. Pairwise accuracy is computed on the 805 heldout pairs reconstructed from the native
corpus (2 fewer than the literature's reported 807, from the same 4 heldout comments already
dropped for unparseable scores).

### 4. Metric definitions
**PR-AUC**: identical definition to every other figure (average precision), with no-skill = the
heldout fold's own positive rate (0.5291 — much higher than CMV's own ~0.20–0.24, since WA's
negative examples are constructed differently; raw PR-AUC is not comparable across the two
datasets for this reason). **Pairwise accuracy**: within each winner/loser comment pair, the
fraction where the model scores the actual winner higher than the actual loser (ties split 0.5) —
the metric the cited literature reports, not PR-AUC, so it's shown in its own panel rather than
merged onto one axis with PR-AUC.

### 6. Methodological limitations
- **This is a transfer of the training methodology, refit on WA — not zero-shot transfer, and not
  a direct reproduction of the same model or an identical experiment.** The architecture and
  training configuration (`RobustScaler` + `SMOTE` + `XGBoost`) were selected once on the CMV data
  and reused unchanged; a **new model instance was fit on WA's own training split** and evaluated
  on WA's own heldout split. No model-family or hyperparameter selection was performed specifically
  for WA. Say explicitly: "same method, retrained on WA's data," not "the same model" or "the same
  experiment repeated."
- **Literature bands are context, not a like-for-like benchmark.** Labruna et al. (2026) score a
  different, LLM-native pipeline on a task framing that isn't identical to this project's reused
  architecture; the bands are shown as shaded context only, explicitly caveated on the chart and
  here, not claimed as a direct beat/loss.
- Excludes all results from `wa_quick_experiments.ipynb` (genuine zero-shot/no-refit checks,
  embeddings-on-top, re-adding-concession) — out of scope for this figure and the whole
  presentation, per `RESEARCH_GUARDRAILS.md`.
- The robust core (4 features) is a fixed, pre-registered choice carried over from `07`'s own
  criterion on CMV data, not re-derived or tuned on WA.
- The Winning Arguments validation supports the broader finding that 
  rhetorical-strategy scores contain predictive information in a second dataset. However, it does not 
  establish that their **incremental predictive contribution beyond comment length** replicates to the 
  same extent observed in my original dataset. That stronger claim would require an explicit, 
  comparable length-controlled ablation on WA.

### 7. One-sentence takeaway
Transferring the same training methodology to Winning Arguments — a new model, refit on WA's own
data, not the same model or an identical experiment — reproduces the structural finding that
strategy scores add value, landing in a defensible position against the literature's own
benchmarks.
